# 🦈 The Surfing Shark

The Surfing Shark is a simple browser game I created using **HTML, CSS, and JavaScript**. The player controls a shark moving across the ocean and tries to catch falling objects to earn points.

I built this project as one of my early experiences with JavaScript and web development. It helped me practice working with user input, object movement, collision detection, scoring, and interactive webpage elements.

## 🎮 How to Play

* Use the **left and right arrow keys** to move the shark.
* Catch the falling objects before they pass you.
* Each successful catch increases your score.

## 🛠️ Built With

* HTML
* CSS
* JavaScript

## 💡 What I Learned

Through this project, I gained experience with JavaScript event handling, game logic, collision detection, and connecting HTML, CSS, and JavaScript to create an interactive web experience.

## 🎨 Design

The game's visual assets were created and customized using Canva.
